calendar library

soluna

bidirectional gregorian and chinese lunar calendar conversion for javascript. zero dependencies, one file, node.js and browser, 1900 to 2100.

githubspecchangelog

install

no npm package yet: copy soluna.js into your project.

// node.js
const { solarToLunar, lunarToSolar } = require('./soluna.js');

// browser
<script src="soluna.js"></script>
const { solarToLunar, lunarToSolar } = window.Soluna;

solarToLunar(2024, 12, 28, 15, 30, 0);   // gregorian to lunar
lunarToSolar(2012, 4, 7, false, 12, 0, 0); // lunar to gregorian (4th arg: leap month)

what it does

  • solarToLunargregorian to lunar date, zodiac, stem-branch (干支), bazi four pillars, time period (时辰), festivals
  • lunarToSolarlunar to gregorian, leap month aware
  • month pillartaken from the actual solar term boundary, not the gregorian month edge
  • festivalspublic holidays, buddhist and taoist dates, folk traditions, 三娘煞日
  • moon phase and solar termsreturned with every conversion
  • zero dependenciesa single file that runs in node.js and in the browser
